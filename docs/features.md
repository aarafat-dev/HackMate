# Features List

HackMate v2.0 is packed with features designed for professional penetration testing productivity.

## 🎯 Engagement Features
- **Centralized Dashboard**: Real-time stats on findings, active projects, and critical risks.
- **Engagement Hub**: Manage multiple concurrent projects with distinct targets and scopes.
- **Auto-Progression**: Workflow-aware phases that guide you through PTES milestones.

## ⚙️ Core Tooling
- **Sandboxed Terminal**: Full terminal experience with safety guards and pre-configured tools.
- **Whitelisted Execution**: Prevents accidental dangerous commands while allowing full power of nmap, nikto, etc.
- **Scan persistence**: Automatic saving of scan results and tool outputs.

## 🧠 AI Intelligence
- **Guided Pentesing**: Step-by-step methodology help from a security-specialized AI persona.
- **Output Summarization**: Automatically compress long tool results into actionable findings.
- **Smart Prompts**: Pre-loaded commands for common recon and exploitation tasks.

## 📈 Reporting & Compliance
- **Multi-Format Export**: Generate reports in professional Markdown (for view) and JSON (for machine-readability).
- **Executive & Technical Views**: Tailored content for different stakeholder levels.
- **Findings Archive**: Searchable database of all historical vulnerabilities.

## 🎨 Professional UI
- **Dark Hacker Theme**: High-contrast, easy-on-the-eyes interface with neon green accents.
- **Responsive Workspace**: Works seamlessly across multiple screen sizes.
- **Interactive Modals**: Seamless viewing of complex data (reports, scan results) without losing context.
